# UBIFS fixtures

These are synthetic regression images, not generated by mkfs.ubifs or extracted
from a device. The pre-existing `ubifs` image uses 4096-byte LEBs (below the
formatter's minimum) and contains uncompressed, nested and raw-DEFLATE files.
`ubifs_corrupt` truncates the image before the index. The original fixture's
placeholder index keys were replaced with each referenced leaf's actual key
and the index CRC was recomputed during the port; file payloads and their
expected hashes are unchanged. Its original source description is in
`formats/ubifs.py`; the Rust port uses that reader's documented on-disk facts,
without copying Linux/mtd-utils implementation code.

Regenerate the additional fixtures with:

    python3 tests/fixture_sources/ubifs/generate.py

`ubifs_multiblock` uses 16384-byte LEBs, a two-level index, two master records
per copy (the latest is authoritative), an empty file, a hard link, a skipped
symlink, and an 8988-byte file with a missing middle block. Block 0 uses Python
zlib's raw DEFLATE producer with an 11-bit window; block 2 is uncompressed.
Hashes are computed from literal source payloads and explicit zero-filled holes.
The encoder is independent of the Rust parser. Unused allocation/log metadata
is not populated; the image is not intended for mounting.

`ubi_ubifs` wraps that exact image in a dynamic UBI volume, storing its LEBs in
reverse physical order. Nested fixture checks verify UBI reconstruction and
UBIFS extraction through generic content detection. UBI header CRCs are omitted,
consistent with that reader's documented scope.

Python parity covers both UBIFS images. Rust mutations also check node CRCs,
branch lengths/keys/boundaries, master fallback/divergence/dirty flags,
authentication, duplicate references/keys, file limits and strict bounded raw
DEFLATE completion. LZO, ZSTD, journal replay and authentication remain unsupported.
